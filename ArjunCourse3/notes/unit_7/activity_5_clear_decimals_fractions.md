# VII-3 Linear Equations: Clear Decimals / Fractions

[KEY]
**Multiplication property of equality:** multiply **both** sides by the same nonzero number and the equation stays true. Use it to **clear** decimals (×10, ×100) or fractions (× LCD) so the equation has only integers. Then solve as in VII-1. If the `x` terms match and a **true** leftover remains → infinite; a **false** leftover → no solution.
[/KEY]

## Quick Review Notes

Class packet **VII-3** (Course 3). After VII-1 / VII-2, make decimal and fraction equations easier by clearing the messy numbers first.

### Class method

1. Name the decimals’ place value or the fractions’ LCD.
2. Multiply **every** term on both sides by 10, 100, or the LCD.
3. Distribute if a fraction sits in front of parentheses.
4. Solve (combine, move variables, move constants, divide).
5. Check one/none/infinite the same way as VII-2.

### Guided examples (VII-3 front)

| # | Equation | Clear by | Answer |
|---|----------|----------|--------|
| 1 | `0.4x − 12 = 0.8` | ×10 | **`x = 32`** |
| 2 | `0.05x + 0.3 = 2` | ×100 | **`x = 34`** |
| 3 | `2x − 1/3 = 24 − (8/3)x` | ×3 | **`x = 73/14`** |
| 4 | `3x + 2 = (5/2)x − 1/8` | ×8 | **`x = −17/4`** |
| 5 | `(1/5)(3x + 20) = (1/4)(8 + 2x)` | ×20 | **`x = −20`** |
| 6 | `(1/3)(5x + 1) = (1/6)(2x − 7)` | ×6 | **`x = −9/8`** |

**#1.** `4x − 120 = 8` → `4x = 128` → `x = 32`.
**#5.** `4(3x + 20) = 5(8 + 2x)` → `12x + 80 = 40 + 10x` → `2x = −40` → `x = −20`.

### You Try / Practice (VII-3 back)

| # | Equation | Answer |
|---|----------|--------|
| 1 | `2.7x − 4 = 1.5x + 2` | **`x = 5`** |
| 2 | `3.7x + 7 = 8.1x − 19.4` | **`x = 6`** |
| 3 | `6.2x + 5 − 1.4x = 4.8x + 5` | **infinite** (`50 = 50`) |
| 4 | `0.7x + 1.9 + 0.1x = 5.5 − 4.4x` | **`x = 9/13`** |
| 5 | `x + 3 = −x − 10 − (7/3)x` | **`x = −3`** |
| 6 | `x − 10 = (5/6)x − 7 − (1/3)x` | **`x = 6`** |
| 7 | `(5/8)x − 3/8 = (1/2)x + 7/8` | **`x = 10`** |
| 8 | `(1/8)(5x + 64) = (1/4)(20 + 2x)` | **`x = −24`** |

**#3 vs VII-R #5:** here both sides have `+5`, so the leftovers match (**infinite**). VII-R had `+6` on the right (**no solution**).

**Why clear?** Integers are easier to combine and less error-prone than tenths and eighths. The multiplication property says the new equation has the same solution.

## Common slips
- Multiplying only one side, or skipping a term (the `+5` in #3).
- Clearing tenths with ×10 when a hundredth is present (`0.05` needs ×100).
- Calling #3 no solution because it has decimals — leftovers still decide one/none/infinite.
