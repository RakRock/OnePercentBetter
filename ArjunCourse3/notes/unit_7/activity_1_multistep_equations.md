## Quick Review Notes

### Main Idea
Class packet **VII-1 / Unit 7 (1)** (Course 3): solve **multi-step** linear equations, including **variables on both sides**. Start from a bags-and-cubes scale (Unit 6 VI-3), then drop the drawing when there are too many bags.

### Class method (same order as the worksheet)

**Scale model**
1. Write bags as `x` and cubes as 1.
2. Take the same bags/cubes off both pans (inverse operations).
3. Split remaining cubes equally among remaining bags.

**Too many bags?** Do not draw. Combine like bags, write the equation, then solve.

**Equations with variables on both sides**
1. Simplify what you can on each side (distribute, combine like terms).
2. Move all variable terms to one side.
3. Move all constant terms to the opposite side.
4. Solve (divide or multiply).

### Important Formulas / Rules

| Picture / equation | Result |
|--------------------|--------|
| 5 bags + 2 cubes vs 3 bags + 4 cubes | `5x + 2 = 3x + 4` → **`x = 1`** |
| 12 bags + 5 bags vs 6 bags + 17 cubes | Too many to model → `17x = 6x + 17` |
| `10 − 4x = −9x` | `x = −2` |
| `−2x = 3x + 10` | `x = −2` |
| `10x − 8 + 14x = 40` | `x = 2` |
| `½(6x − 4) = −5x + 1` | `x = 3/8` |
| `−¾(8x + 12) − 3(x − 3) = 0` | `x = 0` |

## Guided example (VII-1 front)

**Scale:** 5 bags and 2 cubes on one side, 3 bags and 4 cubes on the other.

- Equation: `5x + 2 = 3x + 4`
- Subtract 3 bags from both pans: `2x + 2 = 4`
- Subtract 2 cubes from both pans: `2x = 2`
- Each bag has **1** cube.

**Too many bags:** 12 bags and 5 bags on one side, 6 bags and 17 cubes on the other. Drawing 17 bags is messy. Combine like terms: `12x + 5x = 6x + 17`.

**Examples (variables on both sides)**

**1.** `10 − 4x = −9x`  
Add `4x`: `10 = −5x`. Divide by `−5`: **`x = −2`**.

**2.** `−2x = 3x + 10`  
Subtract `3x`: `−5x = 10`. Divide by `−5`: **`x = −2`**.

**3.** `10x − 8 + 14x = 40`  
Combine: `24x − 8 = 40`. Add 8: `24x = 48`. **`x = 2`**.

**4.** `½(6x − 4) = −5x + 1`  
Distribute: `3x − 2 = −5x + 1`. Add `5x` and add 2: `8x = 3`. **`x = 3/8`**.

**5.** `−¾(8x + 12) − 3(x − 3) = 0`  
Distribute: `−6x − 9 − 3x + 9 = 0`. Combine: `−9x = 0`. **`x = 0`**.

**Worked highlights**

**1.** Combine: `2x + 3 = −7`. Subtract 3: `2x = −10`. **`x = −5`**.

**4.** Distribute: `3 + 4x + 20 = 31` → `4x + 23 = 31` → `4x = 8` → **`x = 2`**.

**5.** Distribute the `−3`: `27 = 3 − 18 + 6x` → `27 = −15 + 6x` → `42 = 6x` → **`x = 7`**.

**8.** `−8x + 10 = 8 − 12x − 6` → `−8x + 10 = 2 − 12x` → `4x = −8` → **`x = −2`**.

**11.** `8x + 4 = 4x − 12x + 12` → `8x + 4 = −8x + 12` → `16x = 8` → **`x = 1/2`**.

## Common slips
- Forgetting the sign on distribute: `−3(6 − 2x)` is `−18 + 6x`, not `−18 − 6x`.
- Combining unlike terms (`7x − 12` is not `−5x`).
- Dividing before moving the other variable (`−2x = 3x + 10` is not `x = 3x + 10`).
- Drawing 17 bags instead of combining like terms.
