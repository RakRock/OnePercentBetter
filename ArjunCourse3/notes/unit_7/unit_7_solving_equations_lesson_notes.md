# Unit 7: Solving Linear Equations — Overview

**Class packets VII-1, VII-2, and VII-4**

| Packet | Topic | Key idea |
|--------|-------|----------|
| **VII-1** | Multi-step equations | Bags and cubes with variables on both sides; if there are too many bags, combine like terms. Then: simplify → move variables → move constants → solve. |
| **VII-2** | No / infinite / one solution | After simplifying, variables may cancel. True statement → infinite; false statement → none; otherwise `x = #`. Same bags and same cubes always balance; same bags and different cubes never do. |
| **VII-4** | Word problems | Verbal model → equation → solve. Fee + rate, two descriptions of the same length, two scores that add to a total `T`, and `P = R − C`. |
| **VII-R** | Mixed algebra review | Multi-step (including decimals), no/infinite, camping two-rate, a new NFC total, plus IV/V/VI mixed items. |

Open **VII-1**, **VII-2**, then **VII-4** (Classroom 11/3–11/4), then **VII-R** (Classroom 11/5). Concept Check Unit 7 is a mixed 5-question paper from these packets. **CC 8: The OCHO** covers IV–VII (VI joined-polygon walkway; VII infinite / `x = 0` is one solution / distribute both terms). **CC 9 (11/6):** V Try 4, VI Try 3, VII Try 2.
