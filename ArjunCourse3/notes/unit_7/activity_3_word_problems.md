## Quick Review Notes

### Main Idea
Class packet **VII-4** (Course 3, Classroom 11/3–11/4). After VII-1/VII-2, write the equation from a story, then solve. **CC 8: The OCHO** already asked VII solve/classify (infinite, `x = 0` is **one** solution, distribute both terms).

### Class method

1. **Verbal model** — say the story in math words (start + rate × count = goal).
2. **Equation** — pick a letter for the unknown.
3. **Solve** — same inverse-operation steps as VII-1.

### Important Formulas / Rules

| Story | Equation | Answer |
|-------|----------|--------|
| Aunt $100 + uncle $10/mile = $270 | `100 + 10m = 270` | **`m = 17` miles** |
| $18,500 + $500/month = $20,000 | `18500 + 500t = 20000` | **`t = 3` months** |

## Guided example (VII-4N)

**1. Charity walk.** Verbal: starting 100 plus 10 per mile equals 270.  
`100 + 10m = 270` → `10m = 170` → **`m = 17`**.

**2. Vacation savings.** `18500 + 500t = 20000` → `500t = 1500` → **`t = 3`**.

**3. Same longest side, two descriptions.**  
`½P − 10 = ⅖P + 22` → `½P − ⅖P = 32` → `(1/10)P = 32` → **`P = 320`**.

**4–5. Two scores make the total.**  
`T/5 + 15 + T/3 + 6 = T` → `8T/15 + 21 = T` → `21 = 7T/15` → **`T = 45`**.  
49ers: `45/5 + 15 = 24`. Packers: `45/3 + 6 = 21`. **49ers won by 3**.

## CC 8 (The OCHO) — VII slips to drill
- `2(x + 5) = 2x + 10` → `10 = 10` → **infinite**, not “x = 5”.
- `12x + 11 = 2x + 11 + x` → `9x = 0` → **`x = 0`** (one solution). `9x = 0` is **not** “no solution”; no solution is a **false** leftover like `6 = 0`.
- `4x + 24 = 5(x + 5) + 3x` → distribute **both** terms: `5x + 25`, then `4x + 24 = 8x + 25` → **`x = −1/4`**. Trap: `5(x + 5) = 5x + 5` gives the false 4.75.

## Common slips
- Writing `9x = 0` as no solution.
- Distributing to the `x` only: `5(x + 5) = 5x + 5`.
- For two-score games, adding the extras but forgetting both scores sum to **T**.
- For two descriptions of the same side, adding the expressions instead of setting them equal.
