# VII-2 Linear Equations: No / Infinite Solutions

[KEY]
**One solution:** solve and get `x = #`. **No solution:** variables cancel, **false** statement remains (`6 = 0`). **Infinite solutions:** variables cancel, **true** statement remains (`−2 = −2`). Bags: same bags **and** same cubes → always balanced (infinite). Same bags, **different** cubes → never balances (none). To **build** an equation: match the `x` coefficient. Match the constant too → infinite; leave constants different → none.
[/KEY]

## Quick Review Notes

### Main Idea
Class packet **VII-2 / Unit 7 (2)** (Course 3): after VII-1 multi-step solving, decide **how many** solutions an equation has. Classroom 10/30 notes also flag **CC 8: The OCHO** (IV Try 4, V Try 3, VI Try 2, VII Try 1).

### Class method (same order as the worksheet)

**Scale model**
- Bag = `x`, cube = 1. Take the same bags off both pans.
- If the leftover cubes match, the scale is **always** balanced → **infinite** solutions (you cannot name one bag size).
- If the leftover cubes do not match, the scale **never** balances → **no** solution.

**# of solutions (class chart)**

| Result | What you see |
|--------|----------------|
| **One** | Solve and get `x = #` |
| **None** | Variables eliminated, **false** statement remains |
| **Infinite** | Variables eliminated, **true** statement remains |

### Important Formulas / Rules

| Picture / equation | Result |
|--------------------|--------|
| 3 bags + 2 cubes vs 3 bags + 2 cubes | Always balanced → **infinite** |
| 1 bag + 5 cubes vs 1 bag + 2 cubes | Remove bags: 5 ≠ 2 → **no solution** |
| `8 + 5(x − 2) = 2x − 2 + 3x` | `−2 = −2` → **infinite** |
| `8x − 4 − 2x = 3(2x − 1)` | `−4 = −3` → **no solution** |
| `2(3x + 1) = 3x + 1 + 3x` | `2 = 1` → **no solution** |
| `6x + 10 = 10 − 2x + 10x` | **`x = 0`** (one) |

## Guided example (VII-2 front)

**Scale A:** 3 bags and 2 cubes on each pan. Remove 3 bags: 2 cubes = 2 cubes. True for every bag size → **infinite solutions**.

**Scale B:** 1 bag and 5 cubes vs 1 bag and 2 cubes. Remove the bags: 5 cubes vs 2 cubes. Does not work → **no solution**.

**1.** `8 + 5(x − 2) = 2x − 2 + 3x`  
Distribute: `8 + 5x − 10 = 5x − 2` → `5x − 2 = 5x − 2`. Subtract `5x`: **`−2 = −2` true → infinite**.

**2.** `8x − 4 − 2x = 3(2x − 1)`  
`6x − 4 = 6x − 3`. Subtract `6x`: **`−4 = −3` false → no solution**.

**3.** `2(3x + 1) = 3x + 1 + 3x`  
`6x + 2 = 6x + 1`. Subtract `6x`: **`2 = 1` false → no solution**.

**4.** `6x + 10 = 10 − 2x + 10x`  
Right: `10 + 8x`. Subtract `8x` and 10: `−2x = 0` → **`x = 0`** (one solution).

**Worked highlights**

**1.** `15x + 6 = 15x` → `6 = 0` false → **no solution**.

**5.** `10x + 10x = −3 − 7` → `20x = −10` → **`x = −1/2`**.

**7.** `5x + 35 = 12x + 35` → `0 = 7x` → **`x = 0`**. Do not call this infinite just because the 35s match.

**10.** `5 + 10x = 4 + 10x` → `5 = 4` false → **no solution**.

**11.** Left: `−6 + 12x`. For infinite, the blank must be **12**.

**12.** Left: `−7x + 12`. For no solution, the `x` coefficients must match so they cancel, then `12 = 9` is false. Blank = **−7**.

## Common slips
- Calling `5(x + 7) = 12x + 35` infinite because both sides have +35 — the `x` terms still differ, so `x = 0`.
- Stopping at “variables canceled” without checking true vs false.
- Fill-in for **no** solution: matching the constant instead of the `x` coefficient.
- Fill-in for **infinite**: matching only part of `−3(2 − 4x)` and writing 4 instead of 12.
