# VI-1 Patterns and Modeling: Representing Patterns

[KEY]
Organize a figure sequence in a table: figure number **n**, count of dots/squares, then the **difference** between consecutive counts. When that difference is always the same, it is a **constant difference**. The expression in **n** uses that difference as the coefficient (for example dots = `2n − 1` when the difference is 2 and Figure 1 has 1 dot). Substitute **n** to find a far figure.
[/KEY]

## Quick Review Notes

### Main Idea
Class packet **VI-1** (Course 3 Unit 6): draw the next figures, fill a table, write an expression in **n**, then use it for a large figure number.

### Class method (same order as the worksheet)

1. **Draw** the 4th (and 5th) figure by continuing the visible growth.
2. **Table — column 2 only first:** figure number `n` vs number of dots (or squares).
3. **Expression:** let `n` = figure number. Write an expression for the count in figure `n`.
4. **Substitute:** the 3rd figure uses `n = 3`.
5. **Far term:** plug in 51 or 100.
6. **Differences:** subtract consecutive counts and record the last column.
7. **Name:** when consecutive differences are always the same, it is a **constant difference**.
8. **Relate:** that constant difference is how many dots/squares you add each time, and it is the coefficient of `n` in the expression.

### Important Formulas / Rules

| If consecutive counts add | Then |
|---------------------------|------|
| The same amount `d` every time | **Constant difference** `d` (arithmetic sequence) |
| Figure 1 has `a` items | Count in figure `n` is `a + d(n − 1)` |
| Example: 1, 3, 5, 7, … | `d = 2`, expression `2n − 1` |

## Guided example (VI-1 front, problems 1–10)

**Figures:** Figure 1 has **1** dot. Figure 2 has **3** dots. Figure 3 has **5** dots. Each new figure adds a row of **2** dots.

**1. Draw Figure 4 and Figure 5.**  
Figure 4 has **7** dots. Figure 5 has **9** dots.

**2. Table (dots column)**

| Figure Number (n) | Number of Dots | Difference in # of Dots |
|-------------------|----------------|-------------------------|
| 1 | 1 | — |
| 2 | 3 | 2 |
| 3 | 5 | 2 |
| 4 | 7 | 2 |
| 5 | 9 | 2 |
| 6 | 11 | 2 |
| 7 | 13 | 2 |
| 8 | 15 | 2 |
| 9 | 17 | 2 |
| 10 | 19 | 2 |

**3a. Expression in n:** `2n − 1`  
**3b. For the 3rd figure, substitute `n = 3`.**  
**3c. 100th figure:** `2(100) − 1 = 199` dots.

**4.** Differences are all **2** (already in the table).  
**5.** That is called a **constant difference**.  
**6.** You add **2** dots each figure, so the coefficient of `n` is **2**.

## Practice A (V of dots) — problems 1–5

**Figures:** Figure 1 has **3** dots. Figure 2 has **5** dots. Figure 3 has **7** dots (a V that grows by one dot on each arm).

| n | Dots | Difference |
|---|------|------------|
| 1 | 3 | — |
| 2 | 5 | 2 |
| 3 | 7 | 2 |
| 4 | 9 | 2 |
| 5 | 11 | 2 |
| 6 | 13 | 2 |

**Constant difference:** 2  
**Expression:** `2n + 1`  
**51st figure:** `2(51) + 1 = 103` dots.

## Common slips
- Counting only the new dots instead of the **total** in the figure.
- Using `n = 100` in the difference column instead of in the expression.
- Writing `2n` when Figure 1 is 1 (`2n` would be 2, 4, 6, …).
- Mixing **dots vs squares** on the stair problem.
