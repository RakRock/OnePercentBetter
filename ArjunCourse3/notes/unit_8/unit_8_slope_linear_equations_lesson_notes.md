| Packet | Topic | Key idea |
|--------|-------|----------|
| **VIII-1** | Graphing linear equations | A **linear equation** graphs as a line. **Solutions** are the points `(x, y)` on that line. Make a 3-row table (include `x = 0`), plot, connect. `y = c` is horizontal; `x = c` is vertical. Plug in to test a point. |
| **VIII-2** | Slope | `m = Δy/Δx = rise/run = (y₂ − y₁)/(x₂ − x₁)`. Further from 0 → steeper. Positive / negative / zero / **undefined**. Slope triangles on the same line are **similar**. |
| **VIII-2P** | Slope practice | Same slope skill from graphs, points, and tables, plus collinear check, missing `k`, and mixed review (octagon walkway, equilateral perimeter, NFC total). |
