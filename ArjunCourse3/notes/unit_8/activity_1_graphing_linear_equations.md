# VIII-1 Graphing Linear Equations

[KEY]
A **linear equation** graphs as a straight line. A **solution** is any point `(x, y)` on that line. Graph `y = mx + b` by picking three x-values (a negative, **0**, and a positive), filling a table, plotting, and connecting. For a fraction slope, pick x-values that are multiples of the denominator. `y = c` is a **horizontal** line (y never changes). `x = c` is a **vertical** line (x never changes). To test a point, plug x in and see if you get that y.
[/KEY]

## Quick Review Notes

Class packet **VIII-1 Slope/RoC/Linear Equations: Graphing Linear Equations** (Course 3, Classroom 8-11). Warm-up was Unit 6: if `12x + 9` is pebbles in figure `x`, figures 1–3 have **21, 33, 45** pebbles.

### Vocab
- **Linear equation** → equation whose graph makes a line.
- **Solution** → a point on the graph, written as a coordinate.

**Example.** `y = x + 1`. Solutions include `(−1, 0)`, `(12, 13)`, `(66, 67)`, `(77, 78)`.
- Plug in to check `(−1, 0)`: `0 = −1 + 1`. Yes.
- Missing y when `x = 77`: `y = 77 + 1 = 78`.

### Class method
1. Pick **3** x-values (try a negative, **0**, and a positive). Always include 0 — it is fast to plug in.
2. Fill `y`, write the ordered pairs.
3. Plot and **connect** the points. The line is every `(x, y)` that satisfies the equation, not just the three you plotted.
4. Fraction slope: choose x-values that are **multiples of the denominator** so y comes out clean.

### Guided examples (VIII-1 notes)

| # | Equation | Table / result |
|---|----------|----------------|
| 1 | `y = −2x + 1` | `(−1, 3)`, `(0, 1)`, `(1, −1)` — line down through those points |
| 2 | `y = (1/4)x − 5` | Use multiples of 4: `(−4, −6)`, `(0, −5)`, `(4, −4)` |
| 3 | `y = −(1/3)x + 8` | Use multiples of 3: `(−3, 9)`, `(0, 8)`, `(3, 7)`. Check: if `x = 9`, `y = 5`, so `(9, 5)` is on the line |
| 4 | `y = 5` | Horizontal. y is **always** 5, no matter x. Points like `(−1, 5)`, `(0, 5)`, `(1, 5)` |
| 5 | `x = −3` | Vertical. x is **always** −3, no matter y. Points like `(−3, −10)`, `(−3, 0)`, `(−3, 10)` |
| 6 | `y = −4` | Horizontal through `y = −4` |
| 7 | `x = 7` | Vertical through `x = 7` |
| 8 | Is `(4, 9)` a solution of `y = 2x − 14`? | Plug in: `2(4) − 14 = −6`. **−6 ≠ 9**. **Not a solution** — not a point on the line |

## Extra practice (same skills)
- The line is **all** solutions, not only the plotted points.
- Horizontal: `y =` a number. Vertical: `x =` a number. Do **not** swap them.
- Testing a point is plug-in, not “looks close on the grid.”
