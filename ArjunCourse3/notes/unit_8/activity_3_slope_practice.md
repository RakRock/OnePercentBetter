### From two points (3–6)

**7. Steepest / least steep among 3–6:** compare `|m|`.  
`|−14/5| = 2.8` is furthest from 0 → **#5 steepest**. `|−2/3| ≈ 0.67` is closest to 0 → **#3 least steep**.

### From a table (8–9)

**8.** `x`: −8, −2, 4, 10  `y`: 8, 1, −6, −13  
`(4, −6)` and `(10, −13)`: `m = (−13 − (−6)) / (10 − 4) = −7/6`

**9.** `x`: −3, 2, 7, 12  `y`: 0, 2, 4, 6  
`(7, 4)` and `(12, 6)`: `m = (6 − 4) / (12 − 7) = 2/5`

### Collinear, missing k, zero, undefined (10–13)

**10.** `A(−2, −1)`, `B(1, 5)`, `C(4, 11)` lie on one line if every pair has the same slope.  
`AB`: `(5 − (−1)) / (1 − (−2)) = 6/3 = 2`.  
`BC`: `(11 − 5) / (4 − 1) = 6/3 = 2`. Same `m` → **yes, collinear**.

**11.** Points `(1, 3)` and `(5, k)`, `m = 2`.  
`(k − 3) / (5 − 1) = 2` → `(k − 3)/4 = 2` → `k − 3 = 8` → **`k = 11`**.

**12.** Slope of zero: any **horizontal** line (`y =` a constant).

**13.** `(6, 7)` and `(6, 12)`: **same x-coordinate**, different y → vertical line → slope is **undefined** without computing (would be divide by 0).

### Optional review (14–18)

`4(x − 4) + 24x = 9x − 108(x + 1)`  
`4x − 16 + 24x = 9x − 108x − 108`  
`28x − 16 = −99x − 108`  
`127x = −92` → **`x = −92/127`**. Watch the distribute: `−108(x + 1) = −108x − 108`.

**15–16. Joined regular octagons, side 1.** Hide 2 sides at each join (constant difference 6). Fig 1 = 8, Fig 2 = 14, Fig 3 = 20. Expression **`6n + 2`**. 50th figure: `6(50) + 2 = 302`.

`½P − 20 = ¼P + 10` → `P/4 = 30` → **`P = 120`**.
